# Skills de Claude en español · Aldush Media

Skills gratis para Claude Code, en español. Agrega la tienda una sola vez y después instala las que quieras.

## Instalación

En Claude Code, agrega la tienda (solo la primera vez):

```
/plugin marketplace add aldushmedia/skills
```

Luego instala la skill que quieras con `/plugin install <nombre>@aldushmedia` y abre una sesión nueva de Claude Code.

## Las skills

| Skill | Qué hace | Instalar | Usar |
|---|---|---|---|
| [hiring-panel-skill](plugins/hiring-panel-skill) | Siete Claudes intentan rechazar tu currículum y luego te lo rehace con cada error corregido | `/plugin install hiring-panel-skill@aldushmedia` | `/hiring-panel <tu currículum> <el puesto>` |

Cada skill trae su propia licencia en su carpeta.
